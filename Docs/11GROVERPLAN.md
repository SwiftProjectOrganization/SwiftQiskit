# Grover's algorithm as a playground page

## Context

`10DeutschExample` introduced the playground's first quantum algorithm. Grover's algorithm
is the natural second one: unstructured search over N = 2ⁿ items in O(√N) oracle queries
where classically ~N/2 are needed on average. Like the Deutsch page, it fits the v0.1 API
with **no changes to `SwiftQiskitCore`**:

- The missing controlled-Z is `h(1); cx(0,1); h(1)` — exactly the one CNOT form v0.1
  supports (H X H = Z on the target).
- For the closing 3-qubit section, `h(_:)`/`x(_:)` already embed into any register size
  (only `cx` is 2-qubit-limited), and `QuantumCircuit.apply(_:)` accepts any full 2ⁿ×2ⁿ
  matrix, so CCZ is just `Matrix.identity(size: 8)` with the `[7,7]` entry negated.

> **Update (2026-08-13):** `cx(control, target)` is now general — any distinct pair on an
> n-qubit circuit, via `CNOTGate.matrix(qubits:control:target:)`. The constructions above
> remain valid; the hand-built CCZ is still required, since a doubly-controlled Z cannot
> be built from H/X/Z/CNOT alone.

## The algorithm

One Grover iteration = two reflections on the uniform superposition |s⟩ = H⊗ⁿ|0…0⟩:

1. **Oracle** U_w |x⟩ = (−1)^[x = w] |x⟩ — flip the sign of the marked amplitude. Built as
   CZ conjugated by X on every qubit whose bit in w is 0 (maps |w⟩ ↔ |1…1⟩).
2. **Diffusion** D = 2|s⟩⟨s| − I — reflect every amplitude about the mean (inversion about
   the mean). Built as H-all · X-all · CZ · X-all · H-all, which equals −D (a harmless
   global phase).

Each iteration rotates the state by 2θ toward |w⟩, where sin θ = 1/√N, so
P(success) = sin²((2k+1)θ) after k iterations:

- **N = 4** (2 qubits): θ = π/6 — a *single* iteration gives P = 1 exactly, for every
  choice of marked state. More iterations over-rotate: P cycles 0.25, 1, 0.25, 0.25, 1, …
- **N = 8** (3 qubits): θ = arcsin(1/√8) — the optimal k = round(π/(4θ) − ½) = 2 gives
  P = sin²(5θ) ≈ 0.9453; k = 1, 3, 4 give ≈ 0.7813, 0.3301, 0.0122.

## Changes

### 1. New page `Playgrounds.playground/Pages/11GroverExample.xcplaygroundpage/Contents.swift`

Console-only page in the sectioned style of `10DeutschExample` (banner comments, printed
checks with `// Expected:` annotations; no SwiftUI live view). Structure:

- Intro comment: the search problem, classical cost, the two-reflection geometry.
- **Section 1** — `cz(_:)` from existing gates; check that only |11⟩'s sign flips on |s⟩.
- **Section 2** — the four oracles as a `GroverOracle` struct
  (`name` / `markedIndex` / `apply`), generated by `phaseOracle(marked:)`; check each
  flips exactly its own term of |s⟩.
- **Section 3** — `diffusion(_:)` plus a stage-by-stage walkthrough for marked |10⟩:
  uniform → post-oracle (sign hidden in the phase, probabilities still ¼) → printed
  amplitude mean (0.25) → post-diffusion (|10⟩ at ±1) — inversion about the mean made
  concrete, with a note on the gate construction's global −1.
- **Section 4** — `groverCircuit(oracle:iterations:)`; all four marked states found with
  P = 1.0000 from one query.
- **Section 5** — `measure(shots: 1000)`: every outcome is the marked string (contrast
  with Deutsch's 50/50 ancilla bit).
- **Section 6** — over-rotation: P(marked) for k = 0…4 is 0.25, 1, 0.25, 0.25, 1.
- **Section 7** — the Dirac view (ties to page 08): D = 2|s⟩⟨s| − I built from the outer
  product `s * s†`, filled entrywise (Matrix has no `+`/scalar ops), applied via
  `apply(_:)`; matches the gate diffusion up to the global −1.
- **Section 8** — real Grover on 3 qubits: hand-built CCZ via `apply(_:)`, marked |101⟩,
  P(marked) for k = 1…4 peaking at 0.9453, then 1000 shots at k = 2 (~945 hits).
- Linked with `//: [Previous](@previous)` / `//: [Next](@next)`; `10DeutschExample`
  already carries its `[Next]` marker and page ordering is alphabetical, so `11…` slots
  in with no manifest edit.

  `run()`, `measure(shots:)`, and the Dirac helpers (`Ket`, postfix `†`, outer product).
- No general multi-qubit `cx`/`ccz` in Core (roadmap item; the 3-qubit section shows the
  `apply(_:)` escape hatch instead).
- No SwiftUI live view.
